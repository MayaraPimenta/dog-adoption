## LikedList

### Props
_Nenhuma — consome o store diretamente._

### Eventos emitidos
_Nenhum._

### Estados
- loading: buscando lista do store/API
- empty: nenhum cachorro curtido ainda
- populated: lista com um ou mais cards

### Critérios de aceite
- [x] Exibe todos os cachorros curtidos pelo usuário
- [x] Cada item exibe foto, nome e raça
- [x] Exibe mensagem de estado vazio quando a lista está vazia
- [x] Lista é atualizada reativamente ao curtir um novo cachorro
